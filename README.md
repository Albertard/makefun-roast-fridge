# roast-fridge

A program that writes one original roast line about a fridge to
`/output/entry.txt` — the whole entry for the make.fun competition
**"One Line, One Laugh: Roast Your Fridge"**
(`u-suzy-one-line-one-laugh-roast-your-fridge-f1063521`).

## The roast

> My fridge has kept the same yogurt since 2019 — at this point it's not expired, it's a tenant with squatter's rights.

117 characters. A specific, recognisable detail (the yogurt that has lived
in the fridge since 2019) with the twist saved for the last few words: it is
no longer expired food, it is a tenant with squatter's rights. It reads
cleanly aloud as a single line, and it is a roast only a fridge can earn.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
